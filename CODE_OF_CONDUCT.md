# Code of Conduct

Memplex is committed to a respectful, evidence-driven community where people can contribute
without harassment or intimidation. The [canonical real-value CLI guide](docs/guides/real-value-cli.md)
shows how the project distinguishes verified behavior from broader claims.

## Scope

This policy applies in repository issues, pull requests, reviews, commits, project documentation,
and other spaces represented as part of the Memplex project. It also applies when someone
publicly represents the project.

## Expected behavior

- Be respectful, specific, and patient across differences in experience, language, and viewpoint.
- Critique code, evidence, and decisions rather than people.
- Report actual commands, counts, failures, and limitations; correct inaccurate claims promptly.
- Protect credentials, private memory, diagnostic data, and backup artifacts.
- Accept proportionate review and make room for others to participate.

## Unacceptable behavior

- Harassment, threats, stalking, discrimination, sexualized attention, or demeaning language.
- Publishing another person's private information or credentials without explicit permission.
- Deliberately falsifying test evidence, hiding failures, or pressuring others to overstate proof.
- Sustained disruption, spam, impersonation, or retaliation against a good-faith reporter.
- Using project channels to promote unrelated commercial, political, or personal campaigns.

## Reporting

Use the [public conduct report form](https://github.com/articultur/memplex/issues/new?template=conduct_report.yml)
for project conduct and enforcement reports. Every submitted field and attachment is public, so
include only information that can be disclosed safely and remove personal data, credentials, and
private memory content.

No project-controlled confidential conduct intake is currently available. If a report cannot be
made safely in public, do not submit it to the repository. GitHub's
[platform abuse form](https://support.github.com/contact/report-abuse) is for platform abuse only;
it is not a Memplex project-enforcement or appeal channel. GitHub Discussions is not enabled and
is not a reporting channel.

## Enforcement

The `articultur/memplex` repository owner reviews reports, may request focused evidence, and will
avoid sharing reporter identity beyond what is needed to investigate. Depending on severity and
history, responses may include a private correction, content removal, a warning, temporary
participation limits, or permanent exclusion from project spaces. Retaliation is itself a
violation. Decisions may be escalated under [GOVERNANCE.md](GOVERNANCE.md).
