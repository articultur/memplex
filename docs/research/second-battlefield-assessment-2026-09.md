# F4: 第二战场评估 — 非陈述性记忆与年尺度负载（2026-09）

Q4 深研 F4 的结论：LifeBench 揭示旧基准饱和（MemOS 仅 55.2%、
Hindsight 40.99%，后者在 LoCoMo/LongMemEval 上 ~90%），其独有的
非陈述性记忆任务（习惯/技能/情绪/偏好，429 问）是 typed 体系未覆盖的
类型。本文给出缺口对照、互证记录与开工决策框架——这是 F4 的交付物
（评估），不是开工令。

## 缺口对照：LifeBench 四类非陈述性记忆 vs memplex typed 体系

| 类型 | LifeBench 含义 | memplex 现状 | 缺口 |
|------|----------------|--------------|------|
| 偏好 preferences | 稳定偏好（口味/选择/倾向） | **已覆盖**：Preference 节点 + BM25 检索腿 + 偏好池 J 0.9333 实证 | 无 |
| 习惯 habits | 高频重复行为及其节奏 | 部分：可落成 Fact（"每周三给芦荟浇水"），但无频率/持续性语义，检索纯词面 | 语义槽缺失（frequency/regularity） |
| 技能 skills | 习得性过程能力 | **最接近已覆盖**：Function 四槽（trigger/condition/action/benefit）即过程语义 | 缺"熟练度/来源经验"元数据 |
| 情绪 emotions | 情感状态及其时间线 | **未覆盖**：无类型、无时间线、无效价 | 完整缺口 |

年尺度维度：LifeBench 单用户 3.66M tokens 跨年累积。我们的 temporal
题靠日期穿线（0.88-0.90），跨年聚合无专门时间索引；agent-native 评测的
"检索随距离退化"结论对我们同样成立（multi-session 0.8647 是当前
最弱池，与距离退化同构）。这是结构性缺口，不属于任何单一类型。

## 互证记录（已落实，无需新工程）

Agent-native 评测（12 系统×5 工作负载）的两条系统级结论与现有设计
互证：

- **局部维护优于全局重组** ↔ 单写者队列 + premise/consolidation 维护
  pass（B1/F3）：维护是局部的、增量的，从不做全局重排。
- **原始内容保留优于摘要** ↔ ADR-013 段落原话层 + primary 融合
  （0.7669 战役实证原话池 > 摘要池）。

这两条是 F4 结论中"对 Memplex 的含义"里可以直接勾销的部分。

## 决策框架

**进入成本**（若立项）：
1. 数据集：LifeBench 采集协议（通话/短信/日历/照片/健康记录）需数据
   许可评估，规模 3.66M tokens/用户×10 用户；
2. 新语义：习惯/情绪的最小实现 = 复用 Fact 骨架 + namespace 频率/效价
   字段（零新表、不动存储格式），技能 = Function 四槽加经验元数据；
3. 评测 harness：非陈述性问题的判分协议与现 LongMemEval judge 不同，
   需自建探针先行（项目纪律：探针先行、确认归因再全量）。

**优先级对照**：J 线已收官（0.916 双口径），P0 检索编排产品化是主线；
第二战场是 Q4+ 候选增长极，不是当前吞吐瓶颈。

**建议**：不立即开工。习惯/情绪两缺口录入能力 backlog；若启动，第一刀
= 习惯的 namespace 语义化探针（事实短语 + frequency 字段对 retrieval
增益是否可测），保持"探针先行、不进在线路径"的项目纪律。开工条件：
P0 完成后或用户拍板。
